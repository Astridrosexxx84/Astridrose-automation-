## 2. Validate the signal with free research

- [ ] Check YouTube Studio **Analytics → Trends** if available for the channel. Its coverage can vary by country, language, and device.
- [ ] Check [Google Trends — Trending now](https://trends.google.com/trending) for the relevant country and recent time window.
- [ ] Search YouTube manually for the exact topic and compare several recent uploads, not just one viral outlier.
- [ ] Record the date and links for each signal.
- [ ] Separate a genuine current trend from evergreen demand, news spikes, and a single creator's unusually large audience.

Do not spend vidIQ AI credits or image/video generation credits during this validation stage.

## 3. Score the opportunity (0–2 each)

0 = weak or unknown; 1 = mixed; 2 = strong and supported by evidence.

| Factor | Score | Evidence / note |
|---|---:|---|
| Recent momentum | /2 | |
| Multiple independent creators are getting views | /2 | |
| Clear viewer question, emotion, or payoff | /2 | |
| Can make a genuinely original version | /2 | |
| Can produce it with free tools and lawful assets | /2 | |
| Can make a strong first 2 seconds / title / thumbnail | /2 | |
| **Total** | **/12** | |

A high score is a shortlist signal, not an automatic publishing decision. If rights, originality, or production feasibility scores 0, stop and redesign the idea.

### Default app allocation

1. **ChatGPT:** research synthesis, script, title options, storyboard, and checklist.
2. **YouTube Studio / Google Trends:** free signal validation.
3. **Pexels or self-created material:** only where useful; record the source and check its license.
4. **Canva:** template, typography, layout, captions, and thumbnail using standard free features.
5. **Runway / HeyGen:** optional, only if a specific approved shot or presenter materially improves the result. Check the connected account's available models and balance first.
6. **Metricool:** schedule only after the content is ready; use ChatGPT for copy instead of consuming its limited AI-text allowance.

Use ordinary editing before AI generation. Never spend a scarce credit merely to explore a concept.

## 5. Rights and quality gate

- [ ] No downloaded/reposted creator video used as if it were ours.
- [ ] Every third-party visual/audio asset has a checked license and recorded source.
- [ ] The finished piece adds meaningful original narration, analysis, reporting, demonstration, or creative work.
- [ ] Claims and dates are checked.
- [ ] Title/thumbnail accurately represent the video; no misleading bait.
- [ ] Captions and audio are understandable on a phone.
- [ ] The final file has been reviewed before publishing.

A private playlist of other creators' videos is for research only, not a content-production shortcut.
