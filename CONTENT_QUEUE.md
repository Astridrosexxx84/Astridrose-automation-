# Content queue

Use this file as the single source of truth for drafts before adding any new automated publishing.

## Status labels
- `IDEA` — not drafted
- `DRAFT` — generated, needs review
- `APPROVED` — approved for the specified platform
- `PUBLISHED` — published; add URL and date
- `HOLD` — policy or quality concern

## Publishing rules
- Do not publish unreviewed AI-generated copy by default.
- Follow each platform's automation, adult-content, and promotion rules.
- No repetitive comments, unsolicited DMs, mass-following, or duplicate cross-posting.
- Log results in `metrics.csv` so we can learn which activity leads to clicks, sign-ups, and sales.
