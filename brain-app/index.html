Advanced · privacy & safety

Privacy notice: this is a public GitHub Pages app and public repository. Browser task data stays in this browser until you send it to the relay. The in-app Run AI relay is wired to send only an opaque run ID to GitHub Actions and store task text and results in your private Supabase workspace; the private dispatch and worker execution have been verified; the app-to-task display is the remaining check. Manual workflow launches and the legacy file-triggered route can still expose content publicly: relay artifacts contain task text and AI responses, and request files can be committed to public Git history. Use only non-sensitive work descriptions; never include passwords, API keys, personal details or confidential material.
